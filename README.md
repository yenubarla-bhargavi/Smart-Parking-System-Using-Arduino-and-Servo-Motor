# Smart Parking System Using Arduino

## Overview

This project implements a Smart Parking System using Arduino, IR sensor, servo motor, and LCD display. The system automates vehicle entry management by detecting vehicles in real time, controlling the parking gate automatically, and displaying parking slot availability.

## Features

- Real-time vehicle detection using IR sensor
- Automatic gate opening and closing
- Parking slot availability monitoring
- LCD display status updates
- Parking Full indication
- User-friendly parking information display
- Low-cost embedded automation solution

## Hardware Components

- Arduino Uno
- IR Sensor
- Servo Motor (SG90)
- 16x2 LCD Display
- Breadboard
- Jumper Wires
- Power Supply

## Working Principle

1. IR sensor detects an approaching vehicle.
2. Arduino processes the sensor signal.
3. If parking slots are available:
   - Gate opens automatically.
   - Vehicle enters parking area.
   - Available slot count decreases.
   - Gate closes automatically.
4. LCD display updates parking information.
5. If no slots are available, the display shows "Parking Full".
